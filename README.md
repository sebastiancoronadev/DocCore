# DocCore 核文 - 文档安全分析引擎

## 项目状态

当前版本: 原型阶段

本项目展示多语言架构在文档安全分析中的应用。
性能指标为各模块理论上限，非端到端处理速度。

## 架构

| 模块 | 语言 | 功能 | 状态 |
|------|------|------|------|
| 编排器 | PowerShell | 流程协调 | 可用 |
| 二进制模式匹配器 | Rust | 字节级模式匹配 + 哈希计算 | 可用 |
| 文档分析器 | Python | PDF结构分析 + 元数据提取 | 可用 |
| 熵数学分析器 | Python | Shannon/Chi²/Monte Carlo | 修复中 |
| 脚本分析器 | Node.js | 静态脚本检测 | 可用 |
| 内存处理器 | C++ | Buffer操作 | 可用 |
| CDR管道 | Python | 内容清理与重构 | 重构中 |

## 已知限制

- PDF解析使用正则表达式，可被恶意构造绕过
- CDR清理可能破坏PDF结构
- 无进程隔离沙箱
- 全文件加载到内存
